# Zoey Commerce AI

Zoey Commerce AI is a conversational commerce and end-to-end
sales agent being developed for Zoey Bambini.

## Architecture

The platform uses:

- FastAPI
- Celery
- Redis
- LangGraph
- OpenAI
- WhatsApp Cloud API
- Bumpa

## Current milestone

Commit 001 - Foundation

The foundation establishes:

- FastAPI application
- Health endpoint
- WhatsApp webhook skeleton
- Redis infrastructure
- Celery worker
- LangGraph foundation
- Configuration management
- Structured logging
- Automated tests
- Docker support
- GitHub Actions
